# Chofix — промпт миграции (v2, под реальное состояние игры)

## Контекст
Chofix — браузерный симулятор кофейни в университете. Один HTML-артефакт, русский язык, стиль «плоский тёплый минимализм». Игрок от первого лица стоит за баром: большие «инсеты» (помол, темпер, шот, вода, молоко, стим, латте-арт, сиропы) рисуются на canvas `#bi` (440×450 логических пикселей, 2×), клики идут через хит-боксы `HIT`. Спереди — зал с гостями, HUD, тикет, книга рецептов, магазин.

Сейчас: Vite-проект, `src/legacy/NN-*.js` (старое ядро, замыкание), чистые модули `src/game/*` (меню, заказы, фразы, экономика, смена, качество, сохранение), `src/ui/book`, данные `data/*.json` (генерируются Python-скриптами из `chofix_menu.md`). 8 играбельных напитков, 9 рангов, 30 дней прогрессии.

## Жёсткие правила
1. Игра для игрока не меняется: баланс, цены, управление, тайминги, внешний вид — как есть. Любое расхождение — баг миграции.
2. Формулы переносятся 1:1, каждая закрыта характеризационным тестом.
3. Логика (`src/game`) не знает про DOM, window, localStorage, Pixi (запрещено линтером).
4. TypeScript strict, без `any` и `!`.
5. Каждый шаг заканчивается зелёным `npm run check` и регрессией на реальных событиях мыши (деньги после одного напитка: эспрессо 612, американо 673, капучино 648, латте 693, флэт уайт 726, ванильный раф/раф 648).
6. Публикация в артефакт — только после регрессии.

## Архитектура интерфейса (решение владельца: «всё в Pixi» для чистоты)
- **В Pixi:** мир — зал, бар, гости, инсеты станций, эффекты (монеты, пар, искры), реплики и «плавающий» текст, привязанные к миру.
- **HTML/CSS поверх canvas:** HUD, меню, тикет, подсказки-коуч, книга рецептов, магазин, тосты, экраны итогов.
  - За: чёткий текст и кириллица без атласов, доступность и фокус с клавиатуры, прокручиваемые списки, i18n, дёшево править вёрстку.
  - Против: два слоя (синхронизация размеров и ввода), текст не получает шейдеры и эффекты мира.
- **Весь UI в Pixi** — возможная поздняя фаза; делается за тем же интерфейсом `Ui`, поэтому не блокирует остальное.

## Фазы и статус
1. **TS и чистая логика** — типы, `economy/shift/quality/save`, тесты. *(сделано)*
2. **Каркас станций** — интерфейс `Station` (чистая логика, без DOM). *(сделано для сиропа и налива воды/молока; остальные станции — по тому же образцу)*
3. **Ресурсы** — звуки в файлах Opus (`npm run audio`), байты грузятся при открытии, декодируются по первому жесту. *(сделано; ленивые сцены и экран загрузки — когда появятся тяжёлые текстуры)*
4. **Рендер на Pixi v8** — *инсеты бара (сироп, вода, молоко, помол, темпер, шот, пар, заливка) перенесены*: `src/render/*`, сверка пикселей `test/inset_cmp.js` (отличие 0,1–1,2%). Включается автоматически на устройствах с видеокартой; на программном рендере (нет GPU) остаётся старый canvas, потому что там Pixi в 3 раза медленнее (замер: 76 мс против 19 мс на кадр). Принудительно: `#pixi` в адресе, выключить: `#nopixi`. *Не перенесено:* зал и гости (SVG), бар от первого лица (SVG), эффекты и подсказки поверх мира.
5. **Приёмка против оригинала** — деньги по напиткам, сверка скриншотов, профилирование. *(частично: деньги и пиксели инсетов проверены)*
