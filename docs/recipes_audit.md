# Аудит рецептур (части 1 и 2)

Файл собирает `npm run audit:recipes` из живых функций игры (`recipeCard`, `recipeNumbers`): шаги и числа здесь те же, что в баре и книге рецептов. Тексты «было» и «почему» — в `scripts/recipes-audit.ts`.

## Общие правила

- Размер в литрах = объём напитка в чашке V (мл): 0,2 / 0,3 / 0,4 / 0,6 л = 200 / 300 / 400 / 600 мл. Масштаб модели чашки (V / 200)^(1/3): 1,00 / 1,14 / 1,26 / 1,44; эспрессо (чашка 90 мл) 0,77, двойной (120 мл) 0,84.
- Шоты по размеру: 0,2 и 0,3 л = 1, 0,4 и 0,6 л = 2. Один шот 30 мл, около 9 г кофе. Вода или молоко = V − 30·S.
- Молоко до пара = M / (1 + x), M = V − 30·S: капучино x = 0,5, латте и остальные молочные 0,2, флэт уайт 0,1, раф 0,3. Шкала «Пена» в баре = x · 1,1.
- Зоны пара, °C: капучино 60–65, латте 55–62, флэт уайт 55–60, раф и какао 60–65, остальные молочные 55–62. Питчер с термометром: на 2° вниз и 3° вверх.
- Холодные: жидкая часть 0,55·V, лёд 0,3·V (занимает остальное 0,45·V с воздухом между кубиками), лёд кладётся первым; размеры 0,3 / 0,4 / 0,6.
- Сироп в рецепте — 8 мл на помпу, помпы 2 / 3 / 4 / 5 по размеру; его объём вычитается из главной жидкой части, чтобы стакан сходился с V.
- Сумма составляющих сходится с V с допуском 3% (проверяет `test/volumes.test.ts`); шаги и числа книги совпадают с баром (`test/recipeCard.test.ts`).

## Допущения ★

- Эспрессо: цена 70 ₽ — допущение, в меню её не было.

- Матча-тоник: 2 г в 45 мл воды.
- Матча бамбл: 2 г в 45 мл воды.
- Сливочный аэрокано с карамелью: пена 40/55/80 мл, лёд меньше на объём пены.
- Латте сакура-вишня с пенкой таро: сироп вычитается из молока.
- Капучино пряная тыква: щепотка ≈ 0,5 г.
- Милкшейк ванильный: молоко добирает объём.
- Милкшейк банановый: пюре 60/90 г.
- Фраппе карамельный: лёд добирает до V.
- Бабл ти гуава-персик: тапиока 60/85 г.
- Протеин на молоке: порошок ≈ 30 мл.
- Протеин на воде: порошок ≈ 30 мл.
- Шоты по размеру 1 / 1 / 2 / 2; цена «Эспрессо» 70 ₽; раф без молока.
- Гости заказывают любой размер из меню у классических напитков (раньше только 0,2 л); крупные размеры с 3-го дня или 2-го ранга.
- Масштаб чашки: (V / 200)^(1/3); максимум 1,4 на 0,6 л.
