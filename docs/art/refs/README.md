# Референсы для перерисовки Cuppable

Сюда кладём картинки, по которым рисуем. Игровой код эти файлы не читает.

## Структура

```
refs/
  equipment/    кофемашина, холдер и темпер, кофемолка, питчер, чашки, витрина
  interior/     студенческая кофейня: стойка, окна, столики, лампы
  people/       студенты, посетители, барист в фартуке; одежда, позы
  style-like/   3–5 иллюстраций «такое нравится»
  style-dislike/ 3 иллюстрации «такого не надо»
  icons/        наборы иконок, чей характер нравится
```

## Что нужно (минимальный набор)

1. 2–3 фото кофемашины спереди (двухгруппной или одногруппной) и отдельно портафильтра, темпера, кофемолки с воронкой.
2. Питчер для молока с носиком, чашки: капучино, стеклянный стакан, бумажный.
3. 2–3 фото интерьера студенческой кофейни.
4. 5–8 референсов людей: разные возрасты, рюкзак, шарф, вязаная шапка, фартук баристы.
5. 3–5 «нравится» и 3 «не надо» по стилю, любая игра или книжная иллюстрация.

## Правила

- Называем файлы по смыслу: `espresso-machine-front-01.jpg`, `style-like-alto-sky.png`.
- Только свои фото или материалы с разрешённой лицензией (CC0, Unsplash, Pexels). Чужие иллюстрации кладём **только** как ориентир «нравится / не нравится» и не копируем в игру.
- К каждому файлу в имени или рядом в `notes.txt` одна строка: что именно нравится (форма, цвет, линия, деталь).
- Размер до 2 МБ на файл. Для мелочей лучше несколько ракурсов, чем один большой.
- Файлы в git не обязательны: если картинки тяжёлые или лицензия неясна, держим локально и называем в `notes.txt` источник.
