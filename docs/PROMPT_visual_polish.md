Ты работаешь над браузерной игрой Chofix (симулятор кофейни). Сначала изучи проект, потом улучши визуал и анимации.

## 0. Вникни в проект (ничего не меняй, пока не закончишь)

1. Прочитай целиком `CLAUDE.md` и `README.md`. Там правила, архитектура, команды и ловушки.
2. Прочитай `src/render/world/` целиком: `world.ts`, `actor.ts`, `art.ts`, `bar.ts`, `fx.ts`, `svg.ts`. Прочитай `src/legacy/13-fx.js` (движение гостей, барист, небо, эффекты) и `src/legacy/04-customers.js`, `05-day.js`.
3. Подними игру (`npm run dev`) и собери отладочную сборку (`npm run build:debug`), запусти `e2e/world_shot.js` и `e2e/bar_shot.js`, **посмотри скриншоты**. Пойми, как игра выглядит сейчас, прежде чем что-либо чинить.
4. Кратко (10–15 строк) перескажи мне, как устроен рендер, и составь список визуальных проблем, которые нашёл сам. Потом работай.

## 1. Что не меняется

- Геймплей, баланс, цены, управление, тайминги заказов и терпение гостей. Это визуальная задача.
- Стиль: плоский тёплый минимализм, тёплая палитра, рисованные контуры `#4A2F25`, бумажная фактура. Не уходить в реализм, неон или «мультяшный 3D».
- Правила из `CLAUDE.md`: TypeScript strict, логика в `src/game` чистая, `npm run check` и `npm run lint:legacy` зелёные.

## 2. Известные проблемы (начни с них)

1. **Гость за столиком пьёт кофе так, будто выливает его на пол.** Сейчас у него просто поднимается пустая рука. Нужно: чашка в руке, рука с чашкой поднимается к лицу, лёгкий наклон головы, пауза, возврат; чашка не должна «лить». Пар над чашкой. Пока не пьёт, чашка стоит на столе или в руке на уровне груди.
2. **Посадка за столик.** Сейчас сидящий — это стоящая фигура с прямыми ногами, спрятанными под столом. Нужна нормальная сидячая поза: согнутые колени, ступни под столом, спина чуть наклонена к ноутбуку, взгляд на экран; иногда смотрит по сторонам, печатает (руки на ноутбуке), потягивается. Приход к столу: подошёл, отодвинул стул, сел. Уход: встал, взял вещи, ушёл. Сейчас переход мгновенный.
3. Порядок слоёв: идущие к выходу и бару гости проходят **за** сидящим и за столом (уже сделано: `cust` под `sitC` под `fg`). Проверь, что нигде не ломается: гость в очереди, гость уходит, барист.
4. **Общая кривизна анимаций гостей**: ходьба, остановка у стойки, получение напитка, радость/злость. Сейчас детали тела вращаются жёсткими кусками без вторичного движения. Нужно: плавные ускорения и торможения (ease), перекат веса, качание рук с задержкой от тела, наклон головы с запаздыванием, «сжатие и растяжение» при остановке и прыжке радости, моргание и мимика, оживление при ожидании (переминается, смотрит на часы, вздыхает при низком терпении).
5. Барист: плавные руки при готовке (в зале видна только верхняя часть), реакция на заказ, подача напитка, радость при хорошем качестве.

## 3. Чем пользоваться (возможности Pixi v8, которые сейчас почти не используются)

Оцени и применяй по делу, не ради галочки; для каждого приёма проверь стоимость на слабой машине:

- Скелетная/мешевая анимация: `MeshRope`, `MeshPlane`, деформируемые меши для ткани, шарфов, пара, волос, лент; либо Spine-подобный подход на отдельных частях с иерархией суставов (плечо→локоть→кисть, бедро→колено→стопа). Для гостей разбей руки и ноги на два сегмента.
- Спрайтшиты и текстурные атласы вместо множества отдельных растровых частей; общий атлас на всех гостей.
- Фильтры: мягкое свечение (bloom), тень, цветовая матрица для времени суток, лёгкое смещение «дрожания контура» на GPU вместо запекания в SVG. Фильтры должны выключаться на программном WebGL (`world.software`).
- Частицы: пар от напитков, пыль в луче, искры при бонусах, брызги при шоте, капли при наливе.
- Твины и пружины: единая маленькая библиотека (`src/render/world/anim.ts`): ease-функции, spring, последовательности, задержки. Не тяни тяжёлые зависимости без необходимости.
- Текстуры: более богатая бумажная фактура, мягкие тени под предметами, полутона вместо плоских заливок там, где это не ломает стиль; освещение от ламп вечером; отражения на стекле витрины.

## 4. Как работать

1. План на 4–6 шагов: что сначала (проблемы из раздела 2), что потом. Каждый шаг даёт видимый результат.
2. После **каждого** шага:
   - `npm run check` и `npm run lint:legacy` зелёные;
   - `npm run build:debug`, затем `node e2e/world_shot.js dist/artifact.html out.png` и **открой скриншот, посмотри глазами**; для анимаций сделай серию кадров (например 8 кадров подряд через `page.screenshot` с паузой 100 мс или запись покадровой раскадровки) и проверь движение по кадрам, а не по одному снимку;
   - `HASH='#nopixi-lowfx' node e2e/bar_test2.js dist/artifact.html t latte` даёт `served 0 -> 1` и `NO_ERRORS`; `node e2e/food_test.js` и `node e2e/menu_test.js` тоже;
   - в консоли браузера нет `console.warn`/`error` (например, про `Graphics.addChild`).
3. Скорость: на реальной GPU кадр должен укладываться в 16 мс; на программном WebGL игра сама рисует реже. Замерь `e2e/fps.js` или `perf3.js` до и после, не ухудши.
4. Не ломай то, что работает: переход зал↔бар, клики по гостям (`hitArea`), пузырь заказа, полоска терпения, реплика `.say`.
5. Если приём не даёт заметного улучшения или дорог, откати и скажи об этом.
