# Бренд Cuppable

Название пишется латиницей, всегда с заглавной C: **Cuppable**.

## Файлы

- `cuppable-icon.svg`: иконка-плитка с чашкой (favicon, apple-touch-icon). Пар кремовый: горчичный на терракоте даёт только 2,2:1.
- `cuppable-wordmark-on-light.svg`: вордмарк для светлого фона (тёмные буквы, терракотовая чашка).
- `cuppable-wordmark-on-dark.svg`: вордмарк для тёмного фона (кремовые буквы, горчичная чашка). Используется на вывеске игры (титул, экран темпа) и, уменьшенным, на вывеске в баре.

## Палитра

| Цвет | Значение |
|---|---|
| Крем | `#FFF8EC` |
| Тёмно-коричневый (контур) | `#4A2F25` |
| Терракота | `#C4694A` |
| Горчица | `#F0BC55` |

## Правила

- **Одна чашка.** Чашка живёт только в букве «u» вордмарка. Отдельную иконку-чашку рядом с вордмарком не ставим (на вывеске был дубль «две чашки с паром»). Иконка-плитка используется сама по себе (favicon), не рядом с вордмарком.
- **Подпись «Кофе между парами»** пишется с заглавной, шрифт Caveat 600; на вывеске стоит по центру под вордмарком, цвет `#E8CDA8`.
- **Контраст** (измерено): на тёмной вывеске `#3B3A33` буквы `#FFF8EC` 10,8:1, чашка и ручка `#F0BC55` 6,5:1, подпись 7,5:1; на светлом фоне `#FFF8EC` тёмные буквы 11,5:1, терракотовая чашка 3,6:1. Графика ≥ 3:1, текст ≥ 4,5:1. Ручку чашки не красим в тёмный на тёмной панели.

- Светлый вордмарк на светлом фоне, тёмный на тёмном.
- Не растягивать (пропорции `viewBox` 626 : 150) и не менять цвета.
- Минимальная ширина вордмарка 100 px.
- Для favicon использовать иконку, а не вордмарк.
- Буквы нарисованы линиями, а не шрифтом, поэтому текстовых замен в SVG делать не нужно: менять надо сам файл.
- В русских фразах слово «Cuppable» не склоняется: «сохранение игры Cuppable».

PNG (`public/og.png`, `public/apple-touch-icon.png`) получены растеризацией SVG в Chromium через Playwright; `.gitignore` игнорирует `*.png`, но пропускает `public/*.png`. У apple-touch-icon фон квадратный без скруглений (iOS скругляет сама), чашка с полями около 12%.
